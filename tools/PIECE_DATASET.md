# 장기말 학습 데이터셋 제작 도구

영상에서 위치 전용 YOLO로 말을 찾고, **사람이 정답을 붙인 Crop**을 학습용으로 내보낸다.
기존 `janggi/.venv`의 OpenCV·Pillow·Tkinter·Ultralytics를 사용하므로 추가 설치는 필요 없다.
이 도구 자체가 모델을 학습하거나 로봇을 움직이지는 않는다.

```bash
cd ~/doosan_janggi_ws
./tools/run_piece_dataset.sh
```

기본 프로젝트는 `tools/datasets/janggi_pieces/`다. Git에서 제외되므로 데이터와 정답은 별도로 백업한다.
다른 프로젝트를 사용하려면 `--project /경로/프로젝트` 또는 화면의 프로젝트 열기/새로 버튼을 사용한다.

## 1. 영상에서 추출

1. **영상 선택**으로 원본 컬러 MP4·MKV 등을 연다. 코덱 지원은 설치된 OpenCV에 따른다.
2. 추출 간격을 선택한다. 기본 2초이며 1~3초 등 원하는 값을 입력할 수 있다.
3. **촬영 그룹**을 입력한다. 기본값은 영상 이름이며, 같은 촬영을 나눈 영상은 같은 그룹으로 묶을 수 있다.
   이때 Train/Val/Test를 정하지 않는다. 사진과 정답은 한곳에 보관한다.
4. **YOLO로 추출**을 누른다. 기본 모델은 `models/weights_only_piece.pt`다.
5. 작업 중지나 창 닫기를 누르면 이미 저장한 자료·정답은 유지하고 작업을 마무리한다.

원본 영상을 순차 디코딩하고 선택된 프레임에서만 검출한다. 전체 프레임을 추론하며
실시간 UI의 보정판 ROI 자르기를 적용하지 않으므로 기존 UI와 검출 수가 다를 수 있다.
클래스 무관 IoU 0.5 중복 제거 후 기본 여백 0으로 검출 박스에 맞춰 원본 Crop을 저장한다.
`--margin`으로 저장용 원본 Crop의 여백을 바꿀 수 있으나, 학습 전처리는 검출 박스를 기준으로 한다.
검출 종류는 정답으로 자동 채택하지 않는다. 원본 프레임, 박스 좌표, 시간, conf, 모델 해시와 설정을 함께 저장한다.
원본 픽셀 크기는 메타데이터에 유지하며, mm 크기를 자동 측정하는 기능은 없다.

동일 영상은 파일 해시로 구분한다. 같은 모델·박스로 다시 추출한 동일 샘플은 중복 추가하지 않고 기존 정답을 유지한다.
영상이 이미 등록되어 있으면 기존 촬영 그룹을 유지한다.
그룹 이름을 바꾸려면 **원본·그룹 관리**를 사용한다. 시간은 영상의 디코더 시각을 사용하며,
시각을 얻지 못하면 프레임 번호/FPS로 대체하고 샘플 설정에 기록한다.

입력은 `color.mp4` 또는 원본 촬영 영상이다. 박스·예측 글자가 덧붙은 overlay나 가상 board 영상을 학습 원본으로 사용하지 않는다.

## 2. 정답 라벨링

왼쪽에서 샘플을 고르면 원본 Crop, 학습 전처리 미리보기, 원본 판에서의 위치를 표시한다.
오른쪽 정답 버튼을 누르면 **즉시 SQLite에 저장하고 다음 이미지로 이동**한다.
각 정답 버튼은 제공된 SVG의 말 그림과 그 아래 한글 이름·단축키를 함께 표시한다.
왼쪽 열은 초, 오른쪽 열은 한이며, 창이 작으면 버튼 영역에서 휠 또는 스크롤바로 이동한다.
압축파일의 `초 병.svg`(卒)는 프로젝트의 `초 졸` 정답에 연결되어 있다.

| 단축키 | 동작 |
|---|---|
| 1~7 | 초: 궁·차·포·마·상·사·졸 순서 |
| Shift+1~7 | 한: 궁·차·포·마·상·사·병 순서 |
| H | 보류 |
| X | 검출 오류/학습 제외 |
| Ctrl+Z | 마지막 라벨 변경 취소 |
| ←/→ | 이전/다음 샘플 |

`pending`은 미검수, `confirmed`는 정답 확정, `hold`는 보류, `rejected`는 제외다.
필터에서 `all`이나 `confirmed`를 선택해 기존 정답을 수정할 수 있다.
라벨 변경 이력도 저장하며 프로그램을 다시 열어 이어서 작업한다.
숫자 입력칸에 커서가 있을 때는 라벨 단축키를 적용하지 않는다.

선명도(Laplacian 분산)와 이미지 경계 잘림 여부를 참고할 수 있지만 자동 정답 판정이나 자동 품질 제외는 하지 않는다.
추적을 이용한 라벨 전파·지각 해시 기반 유사 이미지 삭제는 아직 없다.

## 3. 내보낼 때 비율과 분배 방식 선택

**분배 설정 / 학습 데이터셋 내보내기**에서 다음 값을 고른다.

- Train / Val / Test 비율(%): 기본 **70 / 15 / 15**, 합계 100. Train은 0보다 커야 한다.
- 분배 방식: **랜덤** 또는 **순서대로**. 기본은 랜덤이다.
- 분배 단위: **사진별** 또는 **촬영 그룹별**. 기본은 사진별이다.
- 클래스당 최소 원본 수: Train/Val/Test 각각 기본 **1 / 1 / 1**. 최소 수는 정답이 있는 각 클래스에 적용한다.
  예: `10 / 3 / 3`이면 초 차·초 상 등 각 클래스에 고유 원본이 최소 16개 필요하다.
  비율이 0인 분할은 최소 수를 적용하지 않으며, 최소 수를 0으로 설정하면 해당 제한을 해제한다.
- 랜덤 seed: 기본 42. 같은 원본·라벨·설정·seed이면 같은 분배를 재생성한다.

**분배 미리보기**로 클래스별 Train/Val/Test 표(전체 원본 수 / 고유 원본 수)를 확인한 뒤 **분배 후 내보내기**를 누른다.
먼저 원본을 Train/Val/Test로 나누고, 그다음 Train 원본만 회전·밝기 증강한다.
원본 폴더와 정답은 이동하거나 변경하지 않는다. 매번 새로운 내보내기 폴더를 생성하므로
같은 자료로 비율이나 방식을 달리한 데이터셋을 만들 수 있다.
기존 카탈로그에 저장된 예전 split 배정은 새 내보내기에 사용하지 않으므로 재추출·재라벨링할 필요가 없다.

**사진별 분배**는 클래스별로 비율을 적용한다. 순서대로는 클래스 안에서 영상 등록 순서 →
프레임 번호 → 검출 저장 순서로 Train, Val, Test를 배정한다. 랜덤은 이 원본 단위를 섞어 배정한다.
완전히 동일한 Crop 해시는 하나의 단위로 묶는다. 같은 Crop에 다른 정답이 있으면 오류로 중단한다.
장수가 정수라 반올림하며, 충분한 단위가 있으면 비율이 0이 아닌 각 분할에 최소 한 단위를 배정한다.
최소 수가 있으면 비율보다 우선 확보한다. 고유 원본이 최소 수 합계보다 적으면 클래스별 부족한 수를 표시하고 내보내기를 중단한다.
최소 수를 0으로 해제한 분할의 누락 클래스는 경고와 `dataset.json`에 표시한다.
동일 Crop 묶음에 여러 장이 있으면 실제 사진 수 비율은 요청 비율과 달라질 수 있다.

**촬영 그룹별 분배**는 그룹 수에 비율을 적용하고 같은 그룹의 사진 전체를 함께 배정한다.
동일 Crop이 여러 그룹에 걸쳐 있으면 해당 그룹들도 묶는다. 사진 수·클래스별 비율은 보장하지 않는다.
그룹 배정을 유지한 결과가 클래스별 최소 고유 원본 수를 충족하지 못하면 내보내기를 중단한다.
이 경우 다른 seed/비율을 시도하거나, 촬영 자료를 추가하거나, 사진별 분배를 선택할 수 있다.
그룹 단위에서는 가능한 배정이 있더라도 현재 랜덤 배정이 기준을 못 채울 수 있다.
임의로 이미지를 복사하거나 증강해 최소 수를 채우지 않는다.

사진별 분배에서는 같은 촬영의 비슷한 사진이 학습과 평가에 함께 들어갈 수 있으므로 성능이 높게 보일 수 있다.
독립적인 성능 평가에는 다른 촬영 세션·배치·조명으로 그룹을 만들고 **촬영 그룹별**을 선택한다.
같은 장면을 여러 영상으로 나눈 경우는 같은 그룹으로 지정한다.

## 4. 회전으로 학습 이미지 늘리기

**Train만 추가 증강/이미지** 기본값은 5다.
Train의 정답 원본이 100장이면 원본 전처리 100장 + 증강 500장 = **600장**을 내보낸다.
Val/Test는 정답 원본당 기본 전처리 이미지 한 장만 만든다.

- 회전: 0° 초과 360° 미만에서 서로 다른 각도를 선택. 기본 간격 0.1°, 최소 0.001°
- 각도 간격은 선택 가능한 각도를 정하는 값이며, 저장 개수는 **추가 증강 / 이미지** 값으로 결정
- 예: 간격 0.1°, 증강 5이면 0.1° 단위의 후보 중 5개 각도로 생성 (모든 3,600장을 만들지 않음)
- 밝기·대비: 각각 0.9~1.1 범위의 약한 변화
- 좌우·상하 반전, 강한 색상 변경, 획 지우기: 적용하지 않음
- 검출 박스 중심과 긴 변 길이로 타이트한 정사각형 영역을 설정
- 잘라 둔 이미지를 돌리지 않고 **원본 프레임에서 그 영역을 회전해 직접 추출**
- 모서리에는 원본 장기판 배경이 들어오며, 회색/검정 패딩을 붙이지 않음
- 정사각형을 기본 224×224 RGB PNG로 변환. 직사각형 박스를 강제로 늘리지 않음
- 파생 이미지에도 원본의 사람이 확인한 정답을 그대로 연결

**회전·밝기 변형 다시 보기**는 미리보기만 바꾼다. 실제 파일은 **학습 데이터셋 내보내기**에서 생성한다.
seed, 각도 간격, 원본에서 샘플링한 네 모서리와 파생별 회전·밝기·대비 수치를 저장하므로 같은 입력/seed로 같은 이미지를 재생성할 수 있다.
원본 Crop과 기존 정답은 수정하지 않는다. 이미 저장한 여백 있는 Crop도 새로 추출할 필요 없이
보존된 원본 프레임과 검출 박스로 새 전처리를 적용한다. 원본 프레임이 없으면 내보내기를 중단한다.
원본 박스 크기는 유지되지만, 정규화 이미지 자체는 실측 크기를 보존하는 입력이 아니다.

**타이트한 정사각형을 같은 크기로 회전하는 방식은 모든 말의 잘림을 보장하지 않는다.**
원형 말은 안정적이지만 각진 말, 비대칭 검출, 이미 잘린 검출에서는 모서리가 일부 잘릴 수 있다.
미리보기를 확인하고 문제가 있는 샘플은 보류/제외한다. 회전 영역이 원본 화면 밖으로 나가는 각도는
선택하지 않는다. 기본 정사각형부터 화면 밖이거나 가능한 각도가 증강 개수보다 적으면 내보내기를
중단하며 원본·정답은 유지한다. 기존 내보내기 결과를 덮어쓰지 않는다.

내보내기 분배 결과에서 클래스별 최소 고유 원본 수를 검사하고, 기준 미달이면 중단한다.
최소 제한을 해제한 분할의 누락은 경고로 기록한다. 아직 정답을 붙인 적 없는 클래스는 자동 추가하지 않으므로,
14종 분류를 원하면 먼저 14종 모두를 라벨링해야 한다.
동일 Crop과 회전 파생본은 같은 split을 유지한다. 서로 다른 정답이 붙은 동일 Crop은 검수를 요청하며 중단한다.
현재 정답에 두 클래스만 있으면 두 클래스 실험용 데이터셋으로 내보낸다.
14종 전체 분류기를 만들려면 통계에서 14종 모두 라벨·분리가 준비됐는지 확인한다.

## 저장 구조

```text
tools/datasets/janggi_pieces/
├── catalog.sqlite              # 정답·검수 상태·출처·그룹·수정 이력
├── frames/<영상 SHA256>/       # 추출된 원본 프레임 PNG
├── crops/raw/                  # 여백을 포함한 원본 크기 Crop
└── exports/dataset_날짜_시간/
    ├── train/blue_cha/*.png     # 기본 전처리 + 추가 증강
    ├── val/blue_cha/*.png       # 기본 전처리만
    ├── test/blue_cha/*.png
    ├── ...                     # 활성 클래스별 폴더
    ├── dataset.json            # 분배 비율·방식·실제 분포·경고·전처리·원본 정보
    └── manifest.jsonl          # 파생 이미지 ↔ 정답 ↔ 원본/박스/변환 연결
```

폴더형 분류 데이터셋이므로 Keras와 Ultralytics Classification 모두의 입력으로 사용할 수 있다.
클래스 순서는 `dataset.json`의 `classes`로 확인한다. 라벨은 `blue_soldier` 등 프로젝트 내부 종류 이름을 쓴다.
이는 기존 탐지 모델의 `blue solder` 같은 원시 클래스 표기와 구분한다.
**Ultralytics의 기본 RandomResizedCrop·좌우 반전 등이 자동으로 꺼지는 것은 아니다.**
향후 학습 설정에서 획이 잘리지 않는 전처리와 반전 제외를 별도로 적용해야 한다.
현재 도구는 학습 명령이나 기존 대국 파이프라인을 바꾸지 않는다.

증강 개수를 0으로 두면 디스크에 파생 이미지를 만들지 않는다.
`piece_dataset.core.augment_image(frame, rng, box=box)`는 원본 프레임과 박스를 입력받는 메모리 내 증강 함수이므로
향후 학습 DataLoader에서 On-the-fly로 재사용할 수 있다. 단, 설정 파일을 저장하는 것만으로 각 프레임워크가 자동 적용하는 것은 아니다.

## GUI 없이 사용

```bash
# 첫 한 프레임만 확인용 추출
./tools/run_piece_dataset.sh --project /tmp/piece_trial \
  --extract tools/captures/video_20261109_223623_956498/color.mp4 \
  --interval 2 --limit-frames 1 --device cpu

# GUI로 그 프로젝트에 정답 붙이기
./tools/run_piece_dataset.sh --project /tmp/piece_trial

# 정답 원본을 70/15/15 랜덤 분배한 후 Train만 증강
./tools/run_piece_dataset.sh --project /경로/프로젝트 --export --ratios 70 15 15 \
  --split-mode random --split-unit sample --min-per-class 1 1 1 --augment 5 --size 224 --angle-step 0.1
```
