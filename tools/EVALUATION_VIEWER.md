# 비전 로그 분석 뷰어

`--log-counts`로 생성한 **CSV + overlay.mp4 + board.mp4**를 한 화면에 동기화한다.
카메라·로봇 없이 실행하며 `janggi/.venv`의 OpenCV, NumPy, Pillow, Tkinter를 사용한다.

워크스페이스 루트에서 실행한다:

```bash
./tools/run_evaluation_viewer.sh

# 기존 실행 폴더를 바로 열기
./tools/run_evaluation_viewer.sh \
  janggi/realtime_ui/evaluations/counts_20261110_031435_010322
```

경로를 생략하면 **로그 폴더 열기** 버튼에서 실행별 폴더를 선택한다.
기록 프로그램을 정상 종료해 MP4 저장을 마친 뒤 연다. 원본 네 파일은 수정하지 않는다.

## 여러 결과 비교

기존 창의 **비교 모드** 버튼으로 비교 창을 열거나 다음 명령으로 바로 실행한다:

```bash
./tools/run_evaluation_viewer.sh --compare

# 두 실행을 열고 영상 4개 배치로 시작
./tools/run_evaluation_viewer.sh /경로/첫번째실행 \
  --compare --add-session /경로/두번째실행 --video-count 4
```

1. **로그 추가**로 비교할 실행 폴더들을 차례로 연다. 추가된 결과에 A, B, C… 식별자와 색을 붙인다.
2. 각 결과의 **체크박스**로 그래프 표시를 켜고 끈다. 선택한 결과의 곡선을 같은 5개 그래프에 겹친다.
   현재값도 A/B별로 표시한다.
3. Y축은 **열어 둔 모든 결과의 공통 비교 구간에서 최솟값~최댓값**으로 계산한다.
   체크를 꺼도 범위가 바뀌지 않는다. 새 로그를 추가하면 공통 범위를 다시 계산한다.
4. **영상 수 2/4**를 선택한다. 2개는 위아래, 4개는 2×2 배치로 옆 열을 추가한다. 각 정사각형 박스는 2개 모드와 같은 445×445 크기를 유지하며 그래프도 오른쪽으로 이동한다. 영상 박스끼리와 영상·그래프 사이에는 외부 여백을 두지 않는다.
   창 폭이 부족하면 하단의 가로 스크롤로 이동할 수 있다. 4개 모드라고 화면 전체를 더 작게 축소하지 않는다.
5. **1~4번 영상 콤보박스**에서 각 칸에 표시할 결과와 영상 종류(overlay/board)를 고른다.
   그래프 체크와 영상 선택은 독립적이다. 그래프를 숨긴 결과의 영상도 볼 수 있다.

시간 X축은 저장 영상의 0초를 맞추고, FPS가 다른 결과는 해당 시각 또는 그 직전의 프레임을 표시한다.
비교 재생·저장 기준 FPS는 가장 높은 입력 FPS다. 프레임 X축은 CSV의 같은 행 번호를 맞추고,
재생·저장 FPS는 첫 번째 결과를 사용한다. **전체 길이는 열어 둔 결과 중 가장 짧은 공통 구간까지만 사용한다.**
각 실행 안에서도 CSV·overlay·board 중 가장 짧은 길이를 사용하며, 실행 간에는 시간 X축이면 최단 재생 시간, 프레임 X축이면 최소 행 수로 맞춘다.
긴 결과의 이후 영상·로그는 뷰어와 내보내기에서 제외하고, 공통 Y축 계산에서도 제외한다. 원본 파일을 실제로 삭제하거나 자르지는 않는다. 실제 촬영 시점이나 움직임을 찾아 자동 정렬하는 기능은 아니다.
같은 원본 영상·시작 구간으로 만든 로그를 비교하는 것이 좋다.
`--playback-fps`를 다르게 설정해 저장한 결과라면 같은 원본 프레임끼리 보려면 프레임 X축을 사용한다.

비교 창의 **분석 화면 MP4 저장**은 현재 체크 상태, 공통 축, 영상 2/4개 및 각 슬롯 선택을 그대로 저장한다.
내보내기 시작 시 설정을 복사하므로 저장 도중 화면 설정을 바꿔도 출력 영상에는 영향을 주지 않는다.
입력 로그·영상은 수정하지 않는다.

GUI 없이 기본 선택(A overlay/board, B overlay/board)으로 비교 영상을 만들 수도 있다:

```bash
./tools/run_evaluation_viewer.sh /경로/첫번째실행 \
  --compare --add-session /경로/두번째실행 --video-count 4 \
  --export tools/reports/comparison.mp4
```

모든 결과에서 같은 신뢰도 기준(`중복 제거` 또는 `전체 검출`)을 사용한다.
서로 다른 모델의 conf는 보정된 정답 확률이 아니므로 신뢰도 수치만으로 정확도 우열을 판단하지 않는다.

## 화면과 조작

- **왼쪽 위**: 검출 박스·라벨이 포함된 overlay 영상
- **왼쪽 아래**: 교차점 인식판 영상
- 두 영상의 외곽 박스는 **정사각형**이며, 내부 영상은 원래 비율을 유지한다.
- **오른쪽 5개 그래프**: 중복 제거 후 말 개수, 판 할당 개수, 평균 신뢰도, 하위 30% 평균 신뢰도, 최저 신뢰도
- 각 그래프 오른쪽에는 **현재 프레임의 실제 값**, 위에는 표시 구간의 **최소·평균·최대**를 표시한다.
- 흰 세로선과 색 점은 현재 프레임이다. 현재까지는 밝은 선, 이후 데이터는 옅은 선으로 표시한다.
- 개수 그래프의 가로 점선은 CSV의 `expected` 값(보통 32개)이다.

**재생/일시정지** 또는 Space로 재생한다. 슬라이더로 위치를 이동하고 ←/→는 한 프레임씩,
−1초/+1초 버튼은 영상 시간으로 1초씩 이동한다. 배속은 0.25·0.5·1·2배 중 선택한다.
배속 설정은 MP4 내보내기에도 적용한다. 예를 들어 0.5배는 같은 프레임을 더 천천히 재생하는 파일을 만든다.

### 그래프가 빠르게 흘러가지 않도록 보기

기본값은 **시간 X축 / 10초 / 따라가기**다. 현재 프레임을 따라 10초 구간이 이동한다.
`고정 구간`으로 변경하면 0~10초, 10~20초처럼 구간을 고정하고 위치선만 이동하도록 볼 수 있다.

- **구간 길이**: 5, 10, 20, 30, 60초 등으로 선택하거나 숫자를 입력하고 적용한다.
- **X축**: 시간 또는 프레임. UI에서 축을 바꾸면 FPS를 이용해 구간 길이를 환산한다.
- **그래프 이동**: 기본 `따라가기`, 필요하면 `고정 구간`으로 변경한다.
- **신뢰도 기준**: 기본 `중복 제거`, 필요하면 `전체 검출`로 변경한다.

각 그래프 Y축은 **해당 지표의 전체 로그 최솟값~최댓값**으로 고정한다. 표시 구간이 이동해도 Y축이 흔들리지 않는다.
모든 값이 같으면 작은 여유를 두고, 미기록 지표만 기본 범위를 사용한다. 기준 개수 점선은 축 범위 안에 있을 때 표시한다.

시간은 **저장된 overlay/board 영상의 재생 시점**이다. CSV의 처리 시간(`elapsed_s`)은 사용하지 않는다.
따라서 로그 기록 당시의 추론 속도와 관계없이 영상과 그래프가 맞고, 원본 영상이 반복된 로그도 연속해서 볼 수 있다.
프레임 X축과 화면 상단의 처리 프레임은 CSV와 같이 1부터 표시한다. 원본 영상 프레임은 별도 표기하며 0부터다.

신뢰도 기본 열은 `dedup_conf_mean`, `dedup_conf_min`, `dedup_conf_bottom30_mean`이다.
전체 검출을 선택하면 `conf_` 열을 사용한다. 0~1을 화면에서는 0~100%로 표시한다.
하위 30%는 **낮은 순 30%의 평균**이며 P30 경계값이 아니다.
이전 로그에 해당 열이 없으면 `미기록`으로 표시하고 데이터를 만들어 넣지 않는다.
신뢰도는 정답과 비교한 정확도가 아니므로, 누락·오검출과 개수 지표도 함께 확인한다.

## 같은 화면을 MP4로 저장

화면 오른쪽 위 **분석 화면 MP4 저장**을 누르면 현재 그래프 설정과 배속으로 **전체 구간**을 내보낸다.
현재 프레임만 저장하는 기능이 아니다. 저장 중 진행률을 표시하며 같은 버튼으로 취소할 수 있다.
취소하면 불완전한 출력은 삭제한다. 내보내기는 별도 작업에서 진행하며 입력 영상은 덮어쓸 수 없다.

출력은 기본/비교 영상 2개 모드에서 **1920×1080**, 비교 영상 4개 모드에서는 **2366×1080**이며, 1배에서 입력 FPS와 동일하며 입력 프레임마다 분석 화면을 하나씩 생성한다.
0.5배라면 출력 FPS는 절반이 된다. 미리보기에서 표시를 건너뛰더라도 내보내기는 구간 내 모든 프레임을 포함한다.
두 영상과 CSV 길이가 다르면 공통 길이까지만 사용하고 경고를 표시한다.

GUI 없이도 내보낼 수 있다:

```bash
./tools/run_evaluation_viewer.sh \
  janggi/realtime_ui/evaluations/counts_20261110_031435_010322 \
  --window 10 --export tools/reports/report.mp4

# 프레임 X축, 600프레임 구간, 느리게 저장
./tools/run_evaluation_viewer.sh /경로/실행폴더 \
  --axis frame --window 600 --speed 0.5 --export tools/reports/report_slow.mp4

# 확인용으로 처음 90프레임만 내보내기 (끝 번호는 제외)
./tools/run_evaluation_viewer.sh /경로/실행폴더 \
  --start-frame 0 --end-frame 90 --export tools/reports/preview.mp4
```

CLI에서는 이미 있는 출력 파일을 덮어쓰지 않는다. `tools/reports/`는 Git에서 제외된다.
미리보기 창에는 해상도를 맞춰 축소해서 표시하지만 MP4는 2개 모드 1920×1080, 비교 4개 모드 2366×1080으로 저장한다.
