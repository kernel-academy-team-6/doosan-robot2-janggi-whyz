# J6 고정 경로의 오프라인 검증

실제 로봇 연결 없이 E0509 URDF와 독립적인 수치 IK로 새 플래너를 교차 확인했다.
`validate.py`는 ROS 서비스·네트워크·카메라·로봇 제어 명령을 사용하지 않는다.

입력 홈은 `[0,-13.694,134.216,0,59.485,90]°`이며, 플랜지 위치는
URDF 기준 약 `[232.990,-0.001,204.961]mm`다.
집기 수평 이동, 소형 하강/상승, 먼 모서리 이동, 궁 하강/상승,
약 501mm 대각선 이동과 중형 하강의 8개 경로를 검사했다.

- 경로별 12~100개 관절 경유점, 합계 292개.
- 모든 경유점의 J6 명령은 정확히 90°.
- 모든 경로는 플래너 내부의 1/4·1/2·3/4 FK 검사(직선에서 0.25mm 이내)를 통과했다.
- 수치 FK 끝점 오차 최대 약 0.000004mm. 이는 수치 계산의 일치도이며 로봇 위치 정확도가 아니다.
- 하강 플랜지 Z는 소형 143mm, 중형 144mm, 대형 145mm.

재현:

```bash
/usr/bin/python3 docs/analysis/locked_wrist_validation/validate.py
```

전체 결과는 `results.json`에 있다. 실제 SDK IK/FK와 실제 컨트롤러 spline 보간,
관절 추종, 주변 물체 충돌을 실물에서 검증한 결과는 아니다.
실제 실행기는 별도로 실제 SDK FK 검사와 이동 중 J6/XYZ/축 방향 피드백 검사를 수행한다.
