# 고정 기준값 132.6717mm + 명령별 원호 높이

> 후속 판 보정: −20mm 고정과 궁 +3mm는 [독립 4점 실측면 + 전 종류 2mm](board_height_leveling_20261113.md)로 대체했다. 그리퍼 원/각도 및 132.6717+H(c)는 유지한다.

사용자의 최신 지정값을 적용했다. 직전 단계의 실측표 보간과 160mm 고정 연장 방식은 대체했다.
`src/janggi_pick_place2/janggi_pick_place2/geometry.py`가 공통 계산 원본이다.

## 계산 기준

```text
B = 132.6717 mm = 102.6717 + 30
θ(c) = 0.532602 + 0.00151819*c             # radians
W(c) = 2*(4.446124 + 56.302390*cos(θ(c)))
H(c) = -28.589039 + 56.302390*sin(θ(c))
c(Wd) = clamp(round((acos((Wd/2 - 4.446124)/56.302390) - 0.532602)/0.00151819), 0, 700)
L(c) = B + H(c)
Z_flange = Z_tip + L(c)                    # flange Z points down
```

H(c)는 이번에 지정한 **0 기준 상대 높이**를 그대로 더한다. 700 기준으로 재정규화하지 않는다.
H(0)≈0, H(700)≈27.6964007mm이므로 유효 길이는 각각 약 132.6717mm, 160.3681007mm다.
수식의 c=700 너비는 약 6.12935mm다. 직전 실측표의 6.3mm와 다른 것은 지정된 근사식의 결과이며
표에 다시 맞추려고 계수를 임의로 바꾸지 않았다.

기존 파라미터 이름 `tcp_length_at_6mm_mm`는 호출 호환성을 위해 유지한다.
**값은 항상 132.6717**이며, 이름과 달리 이제 ‘6mm에서의 유효 길이’가 아니라 고정 기준값이다.
명령/너비별로 파라미터나 컨트롤러 TCP를 갱신하지 않고 계산 결과에 H(c)를 더한다.

너비 요청은 기존처럼 6~106mm를 받는다. 모델의 양 끝 너비를 벗어난 작은 구간은 c=700/0으로 포화한다.
역함수 결과를 정수 명령으로 반올림한 뒤 **그 정수 c와 같은 H(c)**로 목표를 계산한다.
너비식과 높이식에 서로 다른 명령값이 들어가지 않는다.

## 집기와 놓기

- XY는 기존 카메라 인식/판 보정을 사용한다. 집기 직전 재인식도 유지한다.
- 판 Z=-20mm와 말별 팁 높이는 유지한다. TCP/팁 좌표 변환에만 새 길이를 사용한다.
- 픽: 개방한 상태로 접근한 후 닫힌 명령 상태를 예상한 플랜지 Z로 하강한다.
  열린 상태의 팁은 목표보다 조금 높고, 닫히면서 목표 높이에 도달한다.
- 개폐하는 두 명령 사이에서 H가 가장 커지는 경우도 검사한다. 특히 θ=π/2가 구간 안에 있는
  c≈684 부근에서는 양 끝만 비교하지 않고 내부 최대값까지 고려한다.
  최대 유효 길이를 기준으로 하므로 개폐 도중 팁이 목표 아래로 더 내려가지 않게 한다.
- 플레이스: 들고 있는 말의 닫힌 상태 기준으로 하강한다. 릴리스 개도까지의 최대 H도 고려한다.
  보통 벌리면 H가 줄어 팁이 올라간다. 릴리스 후 기존 진입 플랜지 높이로 수직 복귀한다.
- 개폐와 팔 이동을 동시에 미세 보간하는 새 실시간 서보를 넣은 것은 아니다.
  기존 순차 픽앤플레이스에서 **현재 단계와 다음 벌림 상태를 고려한 목표**를 계산한다.
- 실제 말에 막혀 그리퍼가 목표 명령까지 닫히지 않은 상태는 현재 위치 피드백이 없어 직접 알 수 없다.
  상태 출력의 유효 길이는 `command_model_not_feedback`으로 표시한다.

컨트롤러 기준은 J6 플랜지 원점 그대로다. 보정/장면 기준의 222mm나 장착 오프셋을 여기에 합산하지 않는다.
홈 관절 자세, 로봇 PID/물리 모델, 실제 시리얼 프로토콜은 변경하지 않았다.

## 기본 말 프로필 예시

수동 보드 높이 보정이 꺼진 기본 설정, 닫힘 명령 기준이다.

| 말 그룹 | 닫힘 요청 너비 | c | H(c) | B+H(c) | 팁 Z | 플랜지 Z |
|---|---:|---:|---:|---:|---:|---:|
| 작은 말 | 20mm | 619 | 27.440803 | 160.112503 | −18 | 142.112503 |
| 중간 말 | 26mm | 583 | 27.054876 | 159.726576 | −18 | 141.726576 |
| 궁 | 32mm | 548 | 26.520339 | 159.192039 | −17 | 142.192039 |

예를 들어 차를 집을 때 `Z_flange = −18 + 132.6717 + H(583) ≈ 141.7266mm`다.
좌표는 로봇 베이스 기준 mm다.

## TCP 시험 도구

`janggi_tcp_test`의 기본 기준값도 132.6717로 통일했다.
이 도구가 사용하는 연속 명령 궤적에서는 c를 정수로 재반올림하지 않고
`tcp_length_from_command(c)`로 H(c)를 직접 계산한다. 그래야 높이 보상 궤적이 양자화로 계단 형태가 되지 않는다.
그리퍼 명령 자체를 이 문서 작성 중 실제 장치에 보내지는 않았다.

## 적용

`janggi_pick_place2`, `janggi_tcp_test`를 재빌드했다. 이미 실행 중인 UI/실행기는 재시작해야 한다.
새 터미널은 기존대로 다음 환경을 적용한다.

```bash
cd ~/doosan_janggi_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
```

검증은 원/역함수, 정수 명령과 H 일치, 파라미터 불변, 열림→닫힘 중 팁 최저 높이,
중간 원호 최대 높이, 단계별 목표/취소, 게임 어댑터의 종류별 높이, 연속 TCP 보상에 대해 수행했다.
실제 로봇 이동/그리퍼 작동 시험은 실행하지 않았다.

관련 PickPlace2·TCP·게임 어댑터·Gazebo·측정 도구 테스트 합계 **219개 통과**.
재빌드된 설치 경로에서도 새 기본값과 계산 결과를 확인했다.
