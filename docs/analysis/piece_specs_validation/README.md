# 실측 장기말 규격 적용

Gazebo의 몸체·사진 윗면·충돌 형상에 아래 규격을 적용했다. 너비는 정팔각형의 마주 보는
평행한 두 면 사이 최소 거리이며 외접원 지름이 아니다.

| 말 | 최소 너비 | 두께 | 가정 밀도 1200kg/m³로 계산한 질량 |
|---|---:|---:|---:|
| 사·졸·병 | 21mm | 6mm | 2.630g |
| 차·마·상·포 | 27mm | 7mm | 5.073g |
| 궁(초·한) | 33mm | 8mm | 8.661g |

질량은 실측값이 아니다. 기존 플라스틱 가정 밀도와 새 정팔각기둥 부피로 계산했다.
관성은 균일 밀도 정팔각기둥 공식을 사용한다. 사진은 기존 촬영 자산 그대로다.

- 판 위 생성 중심은 각 말 두께의 절반만큼 올린다.
- 물리 상태를 다시 읽을 때도 해당 말 두께의 절반을 빼서 바닥 기준 좌표를 유지한다.
- 기본 Bullet Featherstone의 convex mesh 마진 1mm를 보상하기 위해 충돌 코어의 각 면을
  1mm 안쪽으로 둔다. 바깥 접촉 면이 시각적 규격보다 1mm씩 커지는 것을 방지한다.
  이는 엔진 마진으로 모서리가 약간 둥글어지는 근사이며 완전한 무오차 CAD 접촉은 아니다.
- 로봇 좌표·그리퍼 제어·보정 파일과 인식 모델의 크기 통계는 변경하지 않는다.

## 확인

32개 말의 몸체 치수·충돌 코어·질량·양의 관성·바닥 기준 생성/관측 좌표를 검사했다.
별도 GZ_PARTITION의 headless Bullet 월드에서 세 종류를 낙하시켜 접촉을 확인했다.
판 위 중심 높이의 계산값과 관측값 차이는 소형 0.064mm, 중형 0.080mm, 궁 0.097mm였다.
결과는 `results.json`, 재현 스크립트는 `check.py`에 있다. 실제 로봇이나 실행 중인 사용자
Gazebo에는 이동 명령을 보내지 않았다.

```bash
source /opt/ros/jazzy/setup.bash
source install/setup.bash
python3 docs/analysis/piece_specs_validation/check.py
```

변경한 장면을 보려면 기존 Gazebo를 종료하고 `sim_gazebo.launch.py`를 다시 실행한다.
이번 변경은 Python 장면 코드와 메시 자산이므로 colcon 재빌드는 필요하지 않다.
